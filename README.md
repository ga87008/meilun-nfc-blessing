# 美崙浸信會周年慶｜NFC 數位祝福網站

這是一個純 HTML、CSS、JavaScript 的手機友善靜態網站，包含隨機經文祝福、日常愛心行動、教會簡介與周年隱藏祝福。

## 首頁

網站入口檔案為 `index.html`，放在 repository 根目錄，適合 GitHub Pages 發布。

## 發布前請確認

- 將 Repository 名稱改成合適的英文網址名稱（例如 `meilun-nfc-blessing`），或保留目前名稱；Repository 現在的名稱是 `-`。
- 請由教會確認簡介中的歷史年份、地址、電話、電子郵件與聚會資訊後再公開。
- 教會建築照片目前先以文字版面代替，避免未確認圖片授權就公開使用。
- GitHub Pages 網站會公開在網路上；確認內容適合所有人瀏覽後再發布。

## GitHub Pages

在 Repository 的 **Settings → Pages** 設定發布來源。若使用 GitHub Actions，請選擇 **GitHub Actions** 並新增／啟用發布 workflow；若使用分支發布，請選 **Deploy from a branch**、分支 `main`、資料夾 `/(root)`。
